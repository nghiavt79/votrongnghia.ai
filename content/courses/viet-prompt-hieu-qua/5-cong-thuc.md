## 1. Công thức "Đóng vai"

```
Bạn là [chuyên gia]. Hãy [nhiệm vụ] cho [đối tượng].
```

## 2. Công thức "Từng bước"

```
Hãy suy nghĩ từng bước và giải thích [vấn đề].
```

## 3. Công thức "Có ví dụ mẫu"

```
Viết 5 tiêu đề theo phong cách giống các ví dụ sau:
- [ví dụ 1]
- [ví dụ 2]
```

## 4. Công thức "Hỏi ngược lại"

```
Tôi muốn [mục tiêu]. Trước khi trả lời, hãy hỏi tôi những câu cần thiết để hiểu rõ yêu cầu.
```

## 5. Công thức "Định dạng đầu ra"

```
Trình bày kết quả dưới dạng bảng gồm các cột: [cột 1], [cột 2], [cột 3].
```

> Lưu các công thức này vào ghi chú để dùng lại mỗi ngày.
