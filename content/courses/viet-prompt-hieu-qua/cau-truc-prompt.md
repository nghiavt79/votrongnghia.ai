## Prompt là gì?

Prompt là **câu lệnh bạn gửi cho AI**. Prompt càng rõ, kết quả càng tốt.

## 4 thành phần của một prompt tốt

1. **Vai trò** — AI nên đóng vai ai?
2. **Nhiệm vụ** — cần làm gì?
3. **Bối cảnh** — thông tin nền, đối tượng
4. **Định dạng** — kết quả trình bày ra sao?

## Ví dụ

❌ Prompt yếu:

```
Viết bài về cà phê.
```

✅ Prompt tốt:

```
Bạn là copywriter cho một quán cà phê nhỏ ở Đà Lạt.
Viết bài đăng Facebook giới thiệu món cà phê trứng mới.
Đối tượng: khách du lịch trẻ 20-30 tuổi.
Độ dài khoảng 100 chữ, giọng thân thiện, có 3 emoji và lời kêu gọi ghé quán.
```
